Зачем этот проект

Почти вся аналитика для своего сервера рассчитана на VPS: Plausible нужны Elixir и ClickHouse, Umami — Node, GoatCounter — отдельный бинарник. PlotBird сделан для миллионов сайтов на хостинге за €3, где есть только PHP, MySQL, FTP и панель управления.

Устанавливается в браузере

Семь шагов: проверка окружения, создание таблиц, запись конфигурации, администратор и первый сайт. Ни терминала, ни консольных команд, ни SSH.

Без cookie

Посетитель — это хеш от адреса, браузера и даты с солью. В браузере ничего не сохраняется, между сайтами никто не отслеживается, а хранение исходного IP — отдельное осознанное включение.

Лёгкий по устройству

1,3 КБ JavaScript, заранее собранный CSS, все библиотеки лежат рядом — дашборд работает даже на сервере без доступа в интернет. Изменения схемы приходят обычным SQL и применяются из настроек.

Запуск в три шага

Без сборки, без установки зависимостей, без пакетных менеджеров.

  1. Загрузите архив Скопируйте релиз по FTP и откройте свой домен в браузере.
  2. Пройдите установку Требования, база, схема, администратор, первый сайт. По пути импортируется встроенная база IP, после чего инсталлятор блокируется сам.
  3. Вставьте счётчик Один тег в <head>, уже с вашим идентификатором сайта. Удалите папку install/ — готово. 
<script async defer
        src="https://your-domain.example/assets/tracker.js"
        data-website-id="00000000-0000-0000-0000-000000000000"></script>

Инсталлятор показывает этот фрагмент уже с вашим идентификатором.

На WordPress — без вставки тега

Плагин добавляет счётчик только на публичные страницы, проверяет, что подключение работает, и показывает статистику внутри админки.

PlotBird — статистика в админке WordPress
  1. Установите плагин Скачайте архив с github.com/plotbird/wordpress-plugin и загрузите его через «Плагины → Добавить новый → Загрузить плагин».
  2. Четыре шага без кода Адрес установки, идентификатор сайта и публичная ссылка только для чтения. Каждый шаг проверяет себя: плагин запрашивает счётчик и ищет тег на главной странице.
  3. Смотрите цифры в админке Просмотры, посетители, сессии, среднее время и отказы, график трафика, популярные страницы, источники, страны, устройства, браузеры и цели. Английский и русский — по языку сайта.

Администраторы по умолчанию не считаются, поэтому ваши собственные визиты не попадают в отчёты. Плагин не хранит пароль: статистика читается по публичной ссылке, она только для чтения и её можно отозвать.

Чем отличается от остальных

Каждый инструмент хорош в своём. Разница — в том, где он запускается.

Полное сравнение: что нужно каждому инструменту →

Против Plausible

Та же идея на другом хостинге: Plausible нужны Elixir и ClickHouse, то есть VPS с Docker. PlotBird нужны PHP и MySQL — тот хостинг, за который вы уже платите.

Против Umami

Umami работает на Node. На многих виртуальных хостингах Node нет вовсе, а где есть — его никто не будет держать запущенным.

Против Matomo

Matomo — платформа: плагины, воронки, электронная коммерция, кампании. PlotBird намеренно остаётся небольшим, чтобы ставиться за пять минут и не тормозить на дешёвой машине.

Чего здесь нет

  • Нет воронок, A/B-тестов, отчётов по электронной коммерции и записей сессий.
  • Файлы .htaccess для Apache и сниппет для nginx не проверены на живом сервере, и документация это не скрывает.
  • Независимого аудита безопасности пока не было.
  • Один сервер MySQL по устройству: ни кластера ClickHouse, ни горизонтального масштабирования.

Если воронки и электронная коммерция нужны сегодня, Matomo — более надёжный выбор.
